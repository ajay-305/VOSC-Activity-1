# Tic-Tac-Toe

A simple and fully functional two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Player X and Player O turns
- Automatic winner detection
- Draw detection
- Restart Game button
- Simple and responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Start playing Tic-Tac-Toe.

## How to Play

1. Player X starts the game.
2. Players take turns selecting an empty square.
3. The first player to get three of their symbols in a row, column, or diagonal wins.
4. If all squares are filled without a winner, the game ends in a draw.
5. Click **Restart Game** to play again.
